# Initial development delivery

## October 15: motion, menus, pinning and performance, versions 0.2.51 to 0.2.56

- The prayer card uses the dock's glass (blurred backdrop, tint, sheen, rim light, soft shadow) and its outline moon; it shrinks to a centred countdown pill with fixed-width digits.
- Opening and closing apps animates: new icons pop in, closed ones shrink away, neighbours slide over and the pill's width springs to its new size.
- Right-click on empty dock space, the MinimaDock button, the clock and quick settings opens the same glass menus as the app jump lists, following the system theme.
- The launcher can pin and unpin apps and programs; Windows' own "Pin to taskbar" (desktop icons, File Explorer, Start) also pins to the dock, and pinning again overrides an earlier dock-only unpin.
- Pins and windows from helper programs resolve to the app they belong to (Steam's window is drawn by steamwebhelper.exe): the icon shows the app's name, merges with its pin and launches the real program. Packaged apps launch through their app identity, then app activation, then Explorer, and launch errors show the Windows error code and path.
- Resources were measured live against Windows' taskbar (see performance.md). A resting dock now draws nothing; active use fell from 16% to 13% of one core after the media title stopped scrolling unhovered, springs settled sooner, the caret blink left the frame loop, glass layers were cached and the window region stopped changing every frame.

## October 14: Windows key opens the launcher, version 0.2.46

A low-level keyboard hook on its own thread watches the Windows key in the live dock only. Tapped alone, it opens (or closes) the launcher and reveals an auto-hidden dock. Before the key's release an unassigned key (vkE8) is sent so Start stays closed. Any other key pressed while Windows is held passes through untouched, so Win+E, Win+L, Win+Shift+S and other shortcuts behave as before. A full-screen foreground window (game or video) keeps Windows' own Start behavior. Closing the dock or reverting the trial removes the hook immediately.

## October 14: launcher, versions 0.2.44 and 0.2.45

The MinimaDock button opens a 680×520 glass launcher, designed in a rendered preview before building. Search is local: nothing is sent online while typing, there is no web or ad content, and a "Local only" chip says so.

- Sources: Windows' own All apps list (`shell:AppsFolder`, including Store apps, with icons, read on a background thread), dock actions (Wi-Fi, Bluetooth, microphone, instant clip, `timer 25`, dark/light mode, power), about forty Settings pages, open windows, and files.
- Files come from Windows' Recent items plus the Windows Search index (file names under the user profile, via OLE DB). AppData, `node_modules`, `.git`, dot folders and hidden/system items are filtered out. Only folders Windows indexes can be found by name.
- Answers: arithmetic, percentages ("15% of 80"), unit and °C/°F conversions and "days until dec 25". Enter copies the answer.
- `>` runs a command in a new PowerShell window (inside Windows Terminal when installed; Shift+Enter as administrator). `:` or `emoji` searches about 250 common emoji, drawn in color; Enter copies. `yt`, `g`, `gh`, `wiki` and `maps` followed by words, or a typed web address, open the browser only when Enter is pressed.
- Ranking combines match quality (prefix, word start, every word, initials, close letters in order, one typo) with how often and how recently a result was opened from the launcher (14-day half-life), stored under `HKCU\Software\MinimaDock\Launcher\Usage`. Results are grouped as Top hit, Answer, Web, Windows, Apps, Files, Actions and Settings; matched letters are highlighted.
- The empty launcher shows quick actions, recent apps and recent files, and a glance at the time, next prayer, Wi-Fi, Bluetooth, volume, microphone, battery, updates and any running timer.
- A preview pane shows thumbnails, the start of text files, a folder's contents, or details for the selected app, window, command or link.
- Tab or right-click on a result opens its actions (spring-in menu at the pointer for right-click): open, run as administrator, open with, show in folder, copy path or file, properties, open in Terminal, snap a window left or right, maximize, minimize or close it, and copy names, links or answers. Shortcuts: Ctrl+Enter shows in folder, Ctrl+Shift+C copies the path, Alt+Enter opens properties.
- Power: Lock acts immediately. Sleep, Restart, Shut down and Sign out need a 900 ms hold (a ring fills), then show a five-second countdown that Esc, Cancel or closing the launcher stops. Apps are never force-closed.
- Motion follows the Animate UI references: the selection highlight glides on a spring, rows rise in, menus spring from their anchor, power icons move on hover. Reduced motion settles everything immediately.

`tests/state_machines/launcher_tests.cpp` covers matching, highlights, ranking and answers. Snapshot modes render the launcher with this PC's real apps and files.

## October 11: latest-state media transport and quieter motion, version 0.2.38

The prior play/pause queue could flood slow providers, expire UI intent before queued requests finished, confirm a newer Play from stale Playing while an older Pause had not applied, and allow Windows' pause-induced current-session switch to strand or redirect later clicks. Media transport now keeps one desired state and one outstanding flight. Clicks atomically toggle that state under the controller mutex and update the glyph immediately. Unsent intermediate requests coalesce; a flight requires both acknowledgement and observed stable playback before a subsequent request can dispatch. Toggle-only providers therefore cannot receive overlapping toggles. Next/previous keep their separate FIFO. A 350 ms interaction lease after settlement retains the controlled session; closed sessions release immediately. Pending work polls finitely at 25 ms, interrupts metadata retrieval, and expires unconfirmed flights after two seconds without blind retry. Idle polling remains five seconds.

The shared click animation is now a four percent press, 170 ms monotonic release and faint stationary glow; the expanding outline ring and bounce are removed. Repeated clicks preserve the current release scale. Flyouts use a smaller six DIP lift and one percent scale with the existing reversible 180/150 ms open/close transitions. Dock hit areas, icon size and vertical pill geometry are unchanged. This quieter direction was informed by [Emil Kowalski's motion exercises](https://emilkowal.ski/ui/train-your-judgement), particularly frequent interactions and interrupted animations; numeric tuning is our own design choice.

Optimized warnings-as-errors builds pass, with 21,609 state/layout assertions and 30,030 slow-provider simulation steps including bursts up to 10,001 clicks. Ten actual worker scenarios use owned ABI providers to verify 100/101-click bursts, explicit/toggle-only dispatch, early acknowledgement with 250/900 ms delayed application, missing notifications, session lease/handoff, rejection and timeout. No request overlapped or reached the competing fake session. The real Windows SMTC fixture also passes: Pause is delivered while its GUI processing is withheld, Play is queued against stale Playing, and both requests apply in order before pending intent clears. The fixture sends no commands to other players. Native pixel and layered-flyout/calendar lifecycle regressions pass. Installed-player/user workload testing is still needed; the controlled checks do not claim universal provider behavior. Recovery code is unchanged.

Version 0.2.38 is packaged, but live deployment is blocked. Windows Code Integrity events 3033/3077 confirm the unsigned MinimaDock.exe failed the active signing policy, both through the recovery supervisor and direct startup. Deploy's readiness check timed out and reverted; status reports no active trial. No policy was changed or bypassed. The tested sources and packaged candidate are retained for a policy-accepted build. Changes remain uncommitted.
